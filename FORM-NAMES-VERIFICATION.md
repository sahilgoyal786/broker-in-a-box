## WHY THIS MATTERS

When the AI reads a DocuSign email with an attached PDF, it will:
1. Extract the document title from the PDF
2. Try to match it to our form list
3. If match found → auto-check the compliance box
4. If no match → flag for manual review

**Exact spelling matters:**
- "Wire Fraud Alert Disclosure" ≠ "Wire Fraud Alert"
- "Data Form - Residential" ≠ "Residential Listing Input Form"
- Case sensitive? Hyphen vs dash? All matters for AI matching.
